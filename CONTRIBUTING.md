# Contributing

Keep toys small and independently buildable. Include setup, controls, exact device model and a short hardware test checklist with each project.

For radio fixes, report station URL, firmware/library versions, USB or battery power, Wi-Fi conditions and relevant serial messages. Never include Wi-Fi passwords or a binary containing private credentials.

Verify station URLs against broadcaster-published direct-stream links. Test format, TLS, station switching and recovery on real hardware before marking a preset verified. Credit upstream work and keep its license notices.

Source is public; a license for original code is still pending. Resolve the license and dependency distribution obligations before publishing firmware or accepting external code contributions.
